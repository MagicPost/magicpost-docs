MagicPost exposes a **public REST API** (`/api/v1/*`) and an **MCP server** so you
can manage LinkedIn posts, schedule them, and pull analytics from any program
or LLM client.

## What you can do

- **Generate posts** in your own voice or an imported creator's style
- **Attach chat-provided media** to a draft before scheduling or publishing
- **Schedule and publish posts** to LinkedIn (with same-day & exact-slot warnings)
- **Pull a compact analytics summary** (top posts, totals, averages)
- **List and edit your drafts**
- **Find inspiration** from a global catalogue of high-performing posts
- **Detect and manage leads** from your posts' engagement, scored against your ICPs
- **Work for the accounts of your organisation** as an org admin — almost every MCP tool, and most API endpoints, can act on a member's account
- **Trigger a fresh sync** of your LinkedIn data and wait for completion

Operations are scoped to your own account by default. Org admins can act on
the account of a member they manage, as if they had switched to it in the app
(see [Acting for a member](/mcp/overview#acting-for-a-member-of-your-organisation)).

## Two ways to use it

<AccordionGroup>
  <Accordion title="MCP: for AI assistants (Claude, ChatGPT, Gemini, Cursor and others)" icon="robot">
    The MCP server at `mcp.magicpost.in` exposes the API as **tools** your
    assistant can call. You connect by sign-in, without an API key. The
    recommended way to operate MagicPost from inside a conversation.

    [→ See MCP setup](/mcp/overview)
  </Accordion>
  <Accordion title="REST — for scripts, integrations, and SDKs" icon="terminal">
    The same API is also reachable directly at `api.magicpost.in/api/v1/*`
    with a `Bearer mp_*` token. Use this when you don't need an LLM in the
    loop.

    [→ See API reference](/api-reference/overview)
  </Accordion>
</AccordionGroup>

## Status

- **Base URL** (production): `https://api.magicpost.in`
- **MCP endpoint**: `https://mcp.magicpost.in/mcp`
- **MCP Registry**: `io.github.MagicPost/linkedin-mcp-server`, with examples and
  prompts in the [GitHub repository](https://github.com/MagicPost/linkedin-mcp-server)
- **Authentication**: sign-in (OAuth) for AI assistants, API keys for tools
  and code, both managed from
  [your account settings](https://app.magicpost.in/account?tab=api-keys)
- **Versioning**: only `v1` exists today. Breaking changes will ship under `v2`.
