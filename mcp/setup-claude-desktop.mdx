Claude connects to MagicPost as a **custom connector**. You sign in once and
the same connection works in claude.ai, in the desktop app and on mobile. No
API key, nothing to install.

## Connect

<Steps>
  <Step title="Open the connectors">
    In Claude, open **Settings → Connectors → Add custom connector**.
  </Step>
  <Step title="Paste the address">
    ```
    https://mcp.magicpost.in/mcp
    ```

    Name the connector `MagicPost` and confirm.
  </Step>
  <Step title="Log in to MagicPost">
    A window opens: log in to MagicPost and authorize the connection. The
    window closes and the connector shows as connected.
  </Step>
</Steps>

In MagicPost, **Settings → API & MCP → Connect a tool → Claude** shows the same
steps and tells you as soon as Claude is connected.

## Verify

Open a new conversation, check that MagicPost is enabled in the tools menu, and
ask:

```
List my scheduled posts on MagicPost
```

Claude calls `list_my_posts` and reads back what is coming up. It lists up to
{/* tools:count */}105{/* /tools:count */} tools, fewer if your account manages no member of an
organisation (see [what your client lists](/mcp/overview#what-your-client-lists)).

## Media in claude.ai

claude.ai does not pass the files of a conversation to tools. Ask for the
media in the chat: Claude gives you a private drop link for your own files, and
attaches by itself the visuals and carousels it designs. See
[Media, visuals and carousels](/mcp/media-attachments).

## Disconnect

In MagicPost, open **Settings → API & MCP** and disconnect Claude from your
connections. You can also remove the connector in Claude's settings.

## Alternative: an API key in the desktop config file

If you prefer an API key to a sign-in, the desktop app can also reach
MagicPost through the open-source
[`mcp-remote`](https://www.npmjs.com/package/mcp-remote) bridge. You need
[Node.js](https://nodejs.org) 18 or later and a
[MagicPost API key](/essentials/authentication#creating-a-token).

<Steps>
  <Step title="Locate the config file">
    | OS | Path |
    |---|---|
    | macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
    | Windows | `%APPDATA%\Claude\claude_desktop_config.json` |
    | Linux | `~/.config/Claude/claude_desktop_config.json` |
  </Step>
  <Step title="Add the MCP server block">
    ```json
    {
      "mcpServers": {
        "magicpost": {
          "command": "npx",
          "args": [
            "-y",
            "mcp-remote",
            "https://mcp.magicpost.in/mcp",
            "--header",
            "Authorization:Bearer mp_YOUR_TOKEN_HERE"
          ]
        }
      }
    }
    ```
  </Step>
  <Step title="Fully quit and relaunch Claude Desktop">
    On macOS, **Cmd+Q** (not just closing the window). MCP servers of the
    config file are only loaded at startup.
  </Step>
</Steps>

`mcp-remote` runs on your machine and forwards calls to `mcp.magicpost.in`.
Your key goes to no third party.

## Troubleshooting

<AccordionGroup>
  <Accordion title="The login window closed before the end">
    Remove the connector in Claude's settings and add it again: the sign-in
    restarts from the beginning.
  </Accordion>
  <Accordion title="Claude says it cannot reach MagicPost">
    Check that the connector is enabled in the conversation's tools menu. If it
    is, disconnect it and connect again.
  </Accordion>
  <Accordion title="Authentication error with an API key">
    The key is invalid or revoked. Create a new one from
    [Settings → API & MCP](https://app.magicpost.in/account?tab=api-keys) and
    replace it in the config file.
  </Accordion>
  <Accordion title="The server of the config file does not appear">
    Validate the JSON (`python -m json.tool claude_desktop_config.json`), check
    that `npx` is on your PATH, then run the bridge by hand to read its output:

    ```bash
    npx -y mcp-remote https://mcp.magicpost.in/mcp \
      --header "Authorization:Bearer mp_YOUR_TOKEN"
    ```
  </Accordion>
</AccordionGroup>
