A LinkedIn post can carry up to 9 images, or one video, or one PDF (shown as a
carousel). The MCP gives the assistant several ways to get media onto a draft.
Pick the one that matches where the file comes from:

| The media is... | Use |
|---|---|
| Something the assistant designs (carousel, chart, quote card, infographic) | [`attach_html_slides`](#visuals-and-carousels-designed-by-the-assistant) |
| A file you have, and you work in claude.ai | [`create_media_drop_link`](#your-own-files-from-claudeai-the-drop-link) |
| A file you added to a ChatGPT conversation | [`attach_media_to_post`](#files-added-to-the-chat) |
| A file on your computer, and you work in Claude Code or another local client | [`prepare_post_media_upload`](#local-files) |
| A file already online (public link) | [`attach_media_to_post`](#files-already-online) with `media_url` |
| A file in your MagicPost media library | [`attach_library_media_to_post`](#files-from-your-media-library) |

All of them attach to an existing draft: call `create_or_update_post` first and
keep the returned `post_id`. Then schedule or publish the post as usual.

## Visuals and carousels designed by the assistant

The assistant writes each slide as an HTML page, MagicPost renders it and
attaches the result to the draft. One slide becomes an image, 2 to 20 slides
become a PDF carousel. Nothing has to be downloaded or uploaded, so this works
in every client, claude.ai included.

> Turn this draft into a 6-slide carousel in our brand colors and attach it.

- Formats: `portrait` (1080x1350, the default) or `square` (1080x1080).
- Each slide is checked before anything is attached: text that overflows, is
  cut, or overlaps something. If a slide has a defect, nothing is attached and
  the assistant gets the list of slides to fix, then sends them again.
- Slides are rendered in an isolated browser: no scripts, no external images.
  Inline SVG (charts, icons), small embedded images and Google Fonts work.
- Up to 120 slides rendered per hour per account.

## Your own files from claude.ai: the drop link

claude.ai does not pass the files of a conversation to tools, and the
assistant's own sandbox cannot upload them either. Instead, the assistant
creates a private link for the draft:

<Steps>
  <Step title="Ask for the link">
    "Attach my photo to this draft." The assistant calls
    `create_media_drop_link` and gives you a link.
  </Step>
  <Step title="Drop your files">
    Open the link in any browser, no login needed, and drop your images, video
    or PDF. They attach to the draft as soon as they are uploaded.
  </Step>
  <Step title="Tell the assistant">
    Say it is done: the assistant checks the draft and continues.
  </Step>
</Steps>

The link works for 30 minutes, only for that draft, and for 9 files at most.
It shows only the first lines of the draft. In `add` mode (the default) files
are added after the draft's images; in `replace` mode the first file replaces
the current media.

## Files added to the chat

In clients that hand conversation files to tools (ChatGPT, for example), add
the file to the conversation and ask the assistant to attach it. It calls
`attach_media_to_post` with the file the client provides.

> Attach the image in this conversation to my draft, with the alt text
> "Product analytics dashboard".

If the client does not offer the file to the tool, the assistant uses the drop
link instead.

## Files already online

If the file is reachable at a public `https://` link (an image on a website, a
shared file), the assistant passes it as `media_url` to `attach_media_to_post`.
The link must point to the file itself, not to a page that displays it.

## Local files

With Claude Code or another client that can read your files and make HTTPS
requests:

<Steps>
  <Step title="Prepare the upload">
    `prepare_post_media_upload` with the draft's `post_id`, the file name and
    its MIME type returns an `upload_id` and a short-lived `upload_request`.
  </Step>
  <Step title="Upload the bytes">
    The client sends the file to the signed URL exactly as described by
    `upload_request`. The URL expires after 15 minutes.
  </Step>
  <Step title="Complete the upload">
    `complete_post_media_upload` with the same `post_id` and `upload_id`.
    MagicPost checks the stored file before attaching it.
  </Step>
</Steps>

> Attach the local file at `/absolute/path/to/product.png` to my draft, then
> schedule it for tomorrow at 14:00.

For manual troubleshooting, the upload looks like this:

```bash
curl --fail-with-body --request PUT \
  --header 'x-upsert: false' \
  --header 'cache-control: max-age=3600' \
  --form 'cacheControl=3600' \
  --form 'file=@/absolute/path/to/product.png;type=image/png' \
  '<SIGNED_UPLOAD_URL>'
```

<Note>
  Sandboxed environments, such as code execution in claude.ai, usually cannot
  reach the upload server. The response of `prepare_post_media_upload` then
  tells the assistant to switch to the drop link, or to `attach_html_slides`
  for something it created.
</Note>

## Files from your media library

`list_media_library` lists the files stored in your MagicPost media library,
and `attach_library_media_to_post` attaches one of them to a draft without
uploading it again. `duplicate_post` copies a past post into a new draft, media
included by default.

## Several images, replacing and removing media

- `append=true` adds an image after the draft's images, up to 9. Upload them
  one after the other, in the order they should appear.
- `replace_existing=true` replaces all the current media with the new file.
  The post and its scheduled comments are kept.
- `remove_post_media` removes one attachment (by its URL from `get_post`), or
  all of them with `remove_all=true`. The text and scheduled comments stay.
- `update_post_media` changes the alt text of an image or the title of a PDF.

A video or a PDF is always the only media of a post.

## Supported files

| Media | Formats | Maximum size |
|---|---|---:|
| Images | JPEG, PNG, WebP, BMP, HEIC, HEIF, AVIF | 50 MB |
| Animated images | GIF | 10 MB |
| Videos | MP4, MOV, AVI, WebM, WMV | 200 MB |
| Documents | PDF | 100 MB |

## Draft requirements

The target post must:

- belong to your MagicPost account, or to a member of your organisation you
  manage as an org admin (pass their `member_user_id` to the media tool);
- be unpublished and unscheduled: cancel the schedule, attach, then schedule
  again;
- have no poll.

Organisation admins use the same workflows on a member's draft:

1. Create the draft with `create_member_post` and the member's
   `member_user_id` (`create_or_update_post` only edits a member's draft).
2. Call the media tool with the same `member_user_id`.
3. Schedule it with `schedule_member_post`, or `schedule_post` with the same
   `member_user_id`.

See [Acting for a member](/mcp/overview#acting-for-a-member-of-your-organisation).

## Privacy

Temporary file URLs from a chat client are used only during the tool call.
Signed upload URLs expire after 15 minutes and drop links after 30 minutes;
drop link tokens are stored hashed. MagicPost checks the type, size and
content of every file before attaching it. Temporary and signed URLs are never
stored in the post or in tool audit data.

## Common errors

| Error | What to do |
|---|---|
| `invalid_file_reference` | The client did not pass the file: use the drop link. |
| `slide_layout_issues` | Fix the listed slides and send all the slides again. |
| `media_upload_already_pending` | Complete or wait for the pending upload; creating a drop link frees it. |
| Signed upload expired | Call `prepare_post_media_upload` again. |
| Upload validation failed | Check the extension, MIME type, size and file contents. |
| Unsupported type or file too large | Convert or compress the file to a supported format and size. |
| `too_many_images` | A post holds 9 images at most: remove one or replace them. |
| `media_append_not_images` | A video or a PDF must be alone: use `replace_existing=true`. |
| Post is scheduled | Cancel the schedule, attach the file, then schedule again. |
| Post contains a poll | Remove the poll (`create_or_update_post` with `remove_poll=True`) or use another draft. |
