Cursor connects to the remote MagicPost MCP server over streamable HTTP and
signs you in through the browser. No API key, no local bridge.

## Connect

<Steps>
  <Step title="Add the server to mcp.json">
    Open `~/.cursor/mcp.json` (or `.cursor/mcp.json` in a project) and add:

    ```json
    {
      "mcpServers": {
        "magicpost": {
          "url": "https://mcp.magicpost.in/mcp"
        }
      }
    }
    ```
  </Step>
  <Step title="Log in to MagicPost">
    Cursor asks you to sign in: log in to MagicPost in the window that opens
    and authorize the connection.
  </Step>
  <Step title="Check the server">
    The `magicpost` row of Cursor's MCP settings shows the number of tools
    loaded: up to {/* tools:count */}105{/* /tools:count */}, fewer if your account manages no member of an organisation (see [what your client lists](/mcp/overview#what-your-client-lists)).
  </Step>
</Steps>

In MagicPost, **Settings → API & MCP → Connect a tool → Cursor** gives the same
block, ready to copy.

## Use it from the chat

Open the Cursor chat in agent mode and ask:

```
Summarize my MagicPost LinkedIn analytics for the last 30 days
```

Cursor asks you to approve the `get_metrics_summary` tool call (you can
auto-approve it from the MCP settings).

Cursor's agent can read your local files, so it can attach one to a draft
through the upload workflow: see [local files](/mcp/media-attachments#local-files).

## Alternative: an API key

To connect with a [MagicPost API key](/essentials/authentication#creating-a-token)
instead of signing in, send it as a header:

```json
{
  "mcpServers": {
    "magicpost": {
      "url": "https://mcp.magicpost.in/mcp",
      "headers": {
        "Authorization": "Bearer mp_YOUR_TOKEN"
      }
    }
  }
}
```
