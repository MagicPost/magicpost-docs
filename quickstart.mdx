By the end of this page, your assistant can list your scheduled posts, draft
new ones, attach media, schedule them, reply to comments and read your
analytics, all from a normal conversation.

AI assistants connect by **sign-in**: you paste one address, log in to
MagicPost in the window that opens, and that's it. No API key to create or
store. API keys remain the way to connect automation tools (n8n, Zapier, Make)
and your own code: see [Authentication](/essentials/authentication).

<Note>
  The API and the MCP server are included in the Creator plan and above, during
  a free trial, and with a Creator seat in a Team or Agency organisation. On
  Agency, an administrator who uses no seat has access too.
</Note>

## 1. Copy the address

```
https://mcp.magicpost.in/mcp
```

You also find it in the app: **Settings → API & MCP → Connect a tool**, then
pick your assistant.

## 2. Add it to your assistant

<Tabs>
  <Tab title="Claude">
    1. Open **Settings → Connectors → Add custom connector**.
    2. Paste the address and confirm.
    3. Log in to MagicPost in the window that opens.

    One connection covers claude.ai, the desktop app and mobile.
    [More on Claude](/mcp/setup-claude-desktop).
  </Tab>
  <Tab title="ChatGPT, Gemini, Perplexity, Grok, Mistral, Codex">
    1. In the assistant's settings, add a custom MCP connector.
    2. Paste the address and choose the OAuth connection.
    3. Log in to MagicPost in the window that opens.

    [More on these assistants](/mcp/setup-other-assistants).
  </Tab>
  <Tab title="Cursor">
    Add this block to your `mcp.json`, then log in to MagicPost when Cursor
    asks:

    ```json
    {
      "mcpServers": {
        "magicpost": {
          "url": "https://mcp.magicpost.in/mcp"
        }
      }
    }
    ```

    [More on Cursor](/mcp/setup-cursor).
  </Tab>
  <Tab title="Claude Code">
    Run this command, then type `/mcp` in Claude Code and log in:

    ```bash
    claude mcp add --transport http magicpost https://mcp.magicpost.in/mcp
    ```

    [More on Claude Code](/mcp/setup-claude-code).
  </Tab>
</Tabs>

The assistant then appears under **Settings → API & MCP** in MagicPost, where
you can disconnect it at any time.

## 3. Try it

In any conversation, ask things like:

- *"List my scheduled posts on MagicPost"*
- *"Summarize my LinkedIn analytics for the last 30 days"*
- *"Write a post from this transcript, in my voice, and save it as a draft"*
- *"Schedule that draft for tomorrow at 14:00"* (the assistant warns you if
  you already have a post that day before going through)
- *"Reply to the comments on my last post"*

<Note>
  To add media, ask for it in the chat. If your client cannot pass a file to
  the tool (claude.ai), the assistant gives you a private link where you drop
  it. Visuals and carousels it designs are attached directly. See
  [Media, visuals and carousels](/mcp/media-attachments).
</Note>

If the assistant says it has no access to your data, the connector is probably
not enabled in that conversation: check that MagicPost is listed among its
connectors, and connect again if the login window was closed before the end.
